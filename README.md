# Personal Portfolio Website
## Overview
This repository contains the source code for my personal portfolio website, live at [jamyeet.github.io]([https://jamyeet.github.io/Personal-Portfolio-Website/]). The website showcases my work, skills, and passion for building intelligent systems and games. It includes a home page, an about page, a filterable projects page, and a contact page.

## Features
- **Responsive Design:** Optimised for both desktop and mobile devices, with a dark theme and a light game-HUD flavour.
- **Home Page:** An introduction to who I am, quick links to my projects, resume and GitHub, and a featured projects row (the Stealth Guard AI card plays its demo on hover).
- **About Me Page:** My background, skills and interests, an Honours research summary, and a timeline of what I'm working on.
- **Projects Page:** A card grid of my projects with tech tags, descriptions, demo video, and links to GitHub repositories and live demos. Cards can be filtered by category (AI, Games, Web).
- **Contact Page:** Email (with a copy button), GitHub and a downloadable resume.

## Technologies Used
- **HTML:** For the structure of the website.
- **CSS:** For styling and layout (CSS variables, grid and flexbox, no frameworks).
- **JavaScript:** Small vanilla scripts for project filtering, hover-to-play video previews and copying my email.
- **GitHub Pages:** For hosting the website.

## Project Structure
- **index.html:** The home page.
- **past.html:** The About Me page.
- **projects.html:** The projects page with category filters.
- **contact.html:** The contact page.
- **style.css:** Contains all the styles for the website.
- **Resume.pdf:** My resume, linked from the home and contact pages.
- **images/:** Directory containing the images and demo video used on the website, plus the favicon and social preview image.
